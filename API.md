## Sizes
Example :

```html
<p class="bigText">Text</p>
<p class="mediumText">Text</p>
<p class="smallText">Text</p>
```
The CSS code is:

```css
.bigText {
    font-size: 50px;
}

.mediumText {
    font-size: 35px;
}

.smallText {
    font-size: 20px;
}
```


### Big Text: 

*changes the text size to large (50px)*

### Medium Text: 

*changes the text size to Medium (35px)*

### Small Text

*changes the text size to Small (20px)*

## Text Colors

<p class="green">Text</p>
<p class="blue">Text</p>
<p class="yellow">Text</p>
<p class="white">Text</p>

.green {
    color: green;
}

.yellow {
    color: yellow;
}

## Font States

Example:

```html
<p class="bold">Text</p>
<p class="italic">Text</p>
<p class="overline">Text</p>
<p class="lineThrough">Text</p>
<p class="underline">Text</p>
```
The CSS code is:
```css
.bold {
    font-weight: bold;
}

.italic {
    font-style: italic;
}

.underline {
    text-decoration: underline;
}

.lineThrough {
    text-decoration: line-through;
}

.overline {
    text-decoration: overline;
}
```
