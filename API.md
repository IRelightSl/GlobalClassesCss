## Sizes
Example :

```html
<p class="bigText">Text</p>
<p class="mediumText">Text</p>
<p class="smallText">Text</p>
```
The code is written like this ! 

```css
.bigText {
    font-size: 50px;
}

.mediumText {
    font-size: 35px;
}

.smallText {
    font-size: 20px;
}
```


### Big Text: 

*changes the text size to large (50px)*

### Medium Text: 

*changes the text size to Medium (35px)*

### Small Text

*change the text size to Small (20px)*

## Font States

Example:

```html
<p class="bold">Text</p>
<p class="italic">Text</p>
<p class="overline">Text</p>
<p class="lineTrough">Text</p>
<p class="underline">Text</p>
```
The code is written like this !
```css
.bold {
    font-weight: bold;
}

.italic {
    font-style: italic;
}

.underline {
    text-decoration: underline;
}

.lineThrough {
    text-decoration: line-through;
}

.overline {
    text-decoration: overline;
}
```
